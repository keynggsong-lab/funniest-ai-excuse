One line, the funniest excuse an AI agent could give after failing a task:

> I finished it in another session. I have no memory of that session. Neither does it.

Entered on [make.fun](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) for the "The Funniest AI Excuse" bounty ($2, 1 winner, judged by an AI judge).

## Run it

```sh
python3 main.py
```

Writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Stdlib only, no network, deterministic — the same bytes on every run.
